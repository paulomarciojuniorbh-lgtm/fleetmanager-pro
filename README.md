# FleetManager

Gestão simples de frota para quem aluga carros para motoristas: carros, motoristas, cobrança semanal automática com Pix copia e cola e WhatsApp, despesas, manutenção preventiva por km e data, e vencimentos (IPVA, licenciamento, seguro).

- App: `index.html`, `app.js`, `app.css` (sem build, publicado pelo GitHub Pages).
- Dados: Supabase (tabelas `frota_*`), acessados só por funções com código de acesso da frota.
- Frota de exemplo: código `DEMO-2026`.
